# 04 AI 使用与贡献记录

## 使用范围

本轮使用 Codex 协助理解题目、制定轻量方案、编写 Python 代码与文档、运行测试、分析真实模型输出并修正缺陷。项目运行时的真实动作由本机已登录的 Claude Code CLI 所连接模型生成；离线 Mock 的动作由规则代码生成，二者在文件名和 `run_info.backend` 中区分。

## 个人贡献与修改

用户提供题目、验收标准、GitHub 授权与环境接入；本轮代码和文档主要由 AI 生成并由 AI 执行验证。**没有记录到用户手工编写或修改代码**，因此不声称存在未发生的个人编码贡献。用户如在提交后自行修改，应在本文件补记具体文件、修改内容与验证结果。

开发中根据实测修正了：SSH 密钥口令参数、模型入口选择、未检索便结束、空白追问、CLI 临时目录占用和错误报告。所有结论以仓库中的运行记录与测试输出为准。

## 验证责任

AI 执行了 `python -m unittest discover -s tests -v`、六组离线运行与可完成的真实模型运行。真实模型额度不足使部分路径无法复跑，见 [评估](03-evaluation.md)。提交者应亲自复查引用、补齐真实模型冲突/资料外运行后，再把评估状态更新为完全通过。
